
# Cisco Training Phase 2 - All Code

This repository contains all the practical work, examples, and lab exercises completed during Cisco Training Phase 2.

## Projects Included

1. **FastApi_Examples** - Basic examples and practice using FastAPI.
2. **Pagination_lab** - Learning and implementing pagination.
3. **pytest_httpx_lab** - API testing using Pytest and HTTPX.

## Technologies Used

- Python
- FastAPI
- Pytest
- HTTPX
- REST API
- Git & GitHub

## Installation

Clone the repository:

```bash
git clone https://github.com/PapunPal/CiscoTraningPhase2AllCode.git
```

Go to the project folder:

```bash
cd CiscoTraningPhase2AllCode
```

Install required libraries:

```bash
pip install fastapi uvicorn pytest httpx
```

## Run Tests

```bash
pytest -v
```
